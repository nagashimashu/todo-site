# Personal Task Board

Personal Task Board は、スマートフォンとパソコンのブラウザーから利用できるTODO管理サイトです。バックエンドやデータベースは不要で、HTML、CSS、JavaScriptだけで動作します。

## 主な機能

- TODOの追加、編集、削除
- 完了・未完了の切り替え
- 期限、優先度、カテゴリの管理
- キーワード検索
- 状態・優先度・カテゴリによる絞り込み
- 並び替え
- ダッシュボードの集計表示
- localStorageへの保存
- JSONバックアップと復元
- ライトモード / ダークモード / 端末設定に合わせる
- スマートフォン向けレスポンシブデザイン

## 使用技術

- HTML5
- CSS3
- Vanilla JavaScript
- localStorage
- JSONファイルの入出力

## ローカルで確認する方法

### 1. 直接ブラウザーで開く

1. このフォルダを開く
2. `index.html` をダブルクリックしてブラウザーで開く
3. 画面が表示されたら利用開始

### 2. VS Code + Live Server を利用する

1. VS Code でこのフォルダを開く
2. 拡張機能「Live Server」を入れる
3. `index.html` を開いて「Go Live」を選択する
4. ブラウザーでページが開く

## GitHubリポジトリへ登録する方法

1. GitHub にログインする
2. 新しいリポジトリを作成する
3. このフォルダ内のファイルを Git に追加する
4. `git add .`
5. `git commit -m "Initial commit"`
6. `git push origin main`

## GitHub上でファイルを追加・編集する方法

1. GitHub のリポジトリページを開く
2. 「Add file」または「Upload files」を選択する
3. 必要なファイルをアップロードする
4. 変更内容をコミットする

## GitHub Pagesで公開する方法

1. GitHub のリポジトリページを開く
2. 「Settings」→「Pages」を開く
3. Source を「Deploy from a branch」に設定する
4. Branch を `main` または `master` に設定する
5. フォルダを `/root` に選択する
6. 保存して公開URLを確認する

公開URLの形式は概ね次のようになります。

```text
https://<ユーザー名>.github.io/<リポジトリ名>/
```

> GitHub Pagesの画面名や手順は変更される可能性があるため、公開時にはGitHub公式情報も確認してください。

## スマートフォンからアクセスする方法

- ブラウザーで公開URLにアクセスする
- 端末のブラウザーで使い続ける
- ホーム画面に追加してアプリ風に利用する

### Androidでホーム画面へ追加する一般的な方法

1. ブラウザーでサイトを開く
2. 画面上部のメニューを開く
3. 「ホーム画面に追加」または「ショートカットを作成」を選択する
4. 追加を完了する

### iPhoneでホーム画面へ追加する一般的な方法

1. Safari でサイトを開く
2. 画面下の共有ボタンを押す
3. 「ホーム画面に追加」を選択する
4. 名前を確認して追加する

## localStorageの保存仕様

- TODO一覧はブラウザー内の localStorage に保存されます
- テーマ設定や並び替え設定も保存されます
- 端末間やブラウザー間で自動同期されません
- ブラウザーのデータ削除や設定リセットで保存内容が消える可能性があります

## JSONバックアップと復元方法

### バックアップ

1. 画面上部の「設定」ボタンを押す
2. 「JSONバックアップ」を選択する
3. JSONファイルが自動でダウンロードされる

### 復元

1. 「設定」→「JSON復元」を選択する
2. JSONファイルを選択する
3. 「現在のTODOへ追加」または「現在のTODOと置き換え」を選ぶ
4. 復元が完了すると一覧が更新される

## 注意事項

- 個人情報、社内情報、機密情報を登録しないでください
- 資料や顧客情報のメモは使用しないでください
- ブラウザー内で保存されるため、端末のデータ削除で消える可能性があります

## よくある問題と対処方法

### TODOが保存されない

- ブラウザーの保存容量やプライバシー設定を確認する
- シークレットモードやブラウザーの設定で localStorage が無効化されていないか確認する

### 画面が崩れる

- 画面幅が狭い場合は横スクロールが出ていないか確認する
- ブラウザーの拡大率やデバイス設定を確認する

### JSONが読み込めない

- ファイル形式が JSON であることを確認する
- 2MB を超える大きなファイルは拒否されるため、サイズを確認する

### 背景が見づらい

- 「設定」からテーマを切り替える
- 端末設定に合わせるモードを選ぶ
